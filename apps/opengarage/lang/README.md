# Translations

One gettext catalogue per language: `fr.po`, `de.po`, `es.po`, `it.po`, `pt.po`.
English is the language of the texts in the code and needs no file. To add a
language, copy `template.pot` to `<code>.po` and fill it in: every `.po` file of this
folder is built into the program.

How to do it, and the rules to follow:

- English: [docs/en/translating.md](../../../docs/en/translating.md)
- Français : [docs/fr/translating.md](../../../docs/fr/translating.md)
